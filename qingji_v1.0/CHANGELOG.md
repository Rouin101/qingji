# 变更记录

本文件记录可发布版本的用户可见变化。开发中的细节仍以提交记录和测试结果为准。

## 未发布

### 新增

- 真实试用页增加基线摘要导出：只比较已完成且耗时齐全的会话，并单独标明缺失数据与人工登记边界。

- 真实试用数据治理流程，覆盖材料准入、脱敏、云端发送范围、撤回、删除和备份恢复。
- 双人独立标注规范、分歧仲裁规则和真实基线集冻结要求。
- 真实项目试用执行手册，以及项目登记、授权治理、双人标注和使用记录工作簿。
- 首批五个真实试用候选项目、风险分层和建议启动顺序；所有授权状态仍为未确认。
- QJ-P01 项目专用材料准入清单，并将其推进到待授权阶段；未导入任何真实材料。
- 项目内“真实试用记录”页面，可保存和修订耗时、提醒采纳、误报漏报、完成补证、困惑点和下一步动作，并导出 CSV。
- 数据库架构版本 2 与 `pilot_sessions` 表；试用记录随项目备份恢复，旧版 v1 备份缺少该表时按空记录兼容。

### 调整

- 精简六个工作台页面：移动端默认收起侧栏，压缩重复演示提示与摘要卡片，将材料元数据和试用质量计数折叠为可选设置，并让成果页默认展示已核验结论。

## v1.4-alpha 2026-09-22

### 新增

- 项目专属术语表。模型只能提出候选，人工确认后才会写入当前项目并用于检索。
- 审核人自填留痕。逐张和批量审核均可记录审核人，并进入审核历史、完整审计导出和项目备份。
- 数据库版本号与迁移记录。当前数据库架构版本为 1。
- 项目备份记录来源数据库架构版本，并拒绝恢复来自未知更高架构版本的备份。
- 产品边界、架构、数据字典、迁移、开发约定和近期问题清单。

### 调整

- 保存项目术语表后，系统使用已经保存的证据关系重新核验当前项目结论，不额外调用模型。
- 项目术语只参与检索归一化，不修改原文，也不能绕过数量、否定、范围、强度和因果规则。
- 未填写审核人时保持为空，不由系统生成可能被误认为真实身份的占位名称。

### 兼容性

- 旧数据库会在启动时补充项目术语表、审核人字段和架构版本记录，原有数据保持不变。
- 备份格式版本仍为 1；旧版 v1 备份可继续恢复，缺失的新字段按空值处理。

### 验证范围

- 自动化测试、页面端到端流程、固定检索回归和虚构综合评测均纳入发布门禁。
- 内部虚构数据上的结果不代表真实社会实践场景准确率。
