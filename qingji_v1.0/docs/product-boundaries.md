# 青迹产品边界

## 产品任务

青迹判断的是当前项目材料对某条表述的支持程度，并保留来源、授权、审核、冲突和补证记录。它帮助社会实践团队写出有证据边界的报告，不替代团队判断现实真相。

## 可以做什么

- 导入已获得处理授权的文本、TXT、Markdown、DOCX 和可提取文本 PDF。
- 在本地识别并脱敏常见敏感信息，分别保存原文和脱敏文本。
- 生成可复核证据卡和结论候选，由人工决定是否采用。
- 对当前材料给出已有支持、部分支持、暂无支持或存在冲突四级结果。
- 生成稳妥改写和补证任务，在证据变化后重新核验结论。
- 导出成果报告、完整审计记录和带校验清单的项目备份。

## 不能宣称什么

- 不是真实性认证、事实核查、伦理审查或法律判断系统。
- 不根据单个受访者、材料份数或团队分析自动推出群体性事实。
- 不把模型建议视为最终裁决，也不允许模型绕过授权、排除状态和引用检查。
- 不把虚构开发集成绩解释为真实项目准确率或与其他系统的优劣比较。

## 当前技术边界

- 当前为本地单用户 Streamlit 应用，审核人是操作人自填，不具有账号认证效力。
- 当前检索以字符片段、关键词、标题与场景加权、全局和项目术语归一化为主，没有向量检索。
- 当前不处理扫描件 OCR、图片、表格结构、音频转写或视频时间轴。
- 当前 SQLite 模式不应直接暴露到公网处理真实敏感材料。

## 真实材料使用条件

1. 项目负责人确认材料用途、授权范围、撤回方式和保留期限。
2. 只导入完成必要脱敏且允许处理的材料；云端模型只接收必要的再次脱敏内容。
3. 测试数据、演示数据和真实材料分开存放，导出与备份按敏感资料保管。
4. 最终报告由项目成员复核原文定位、授权状态、证据关系和表述边界。
