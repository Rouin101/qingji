# 青迹 3 分钟演示脚本

> 适用版本：v1.3 最终参赛版
>
> 演示数据：数字便民服务体验调研（模拟演示）
>
> 核心目标：让评委看到“材料如何变成证据，结论如何被约束，新证据如何改变判断”。

## 录制前准备

1. 在项目目录运行 `.\scripts\run_submission.ps1 -ResetDemo`。
2. 确认首页显示“模拟演示项目”，浏览器缩放设为 90% 或 100%。
3. 关闭通知与无关窗口；完整录制尽量保持在一个连续视频中。
4. 若要演示新建项目的全流程，确认 `.env` 中的模型连接可用，并提前运行 `scripts\test_llm_connection.py`。
5. 准备仓库中的 [`../演示材料/模拟社会实践报告_校园自习空间预约体验调研.docx`](../演示材料/模拟社会实践报告_校园自习空间预约体验调研.docx)。

## 主方案：三分钟稳定闭环

### 0:00–0:25｜介绍问题

**页面操作**：停留在项目概览，指向四步流程、模拟数据提示和当前进度。

**讲解词**：

> 社会实践的问题往往不是没有材料，而是报告中的结论与原始材料脱节。青迹把经授权材料整理成可追溯证据，并检查一句准备写进报告的话是否超出当前证据。

### 0:25–1:10｜查看证据链

**页面操作**：进入“材料与证据 → 审核证据卡”，展开一张证据卡，展示来源定位、原文摘录、审核状态和历史记录。

**讲解词**：

> 每张卡都保留来源材料和原文位置。未确认授权的材料不能进入核验；待复核与人工确认也会明确区分。模型负责生成和建议，引用资格与审核变化始终可追踪。

### 1:10–2:05｜核验过度推广

**页面操作**：进入“结论核验”，打开预置结论“当地居民普遍认为线上办事平台使用困难。”，展示四级结果、范围提醒、稳妥改写、关联证据和智能体执行轨迹。

**讲解词**：

> 现有材料能说明个别使用者遇到困难，却不能证明“当地居民普遍认为”。系统会检查“普遍”这类强量词，展示支持、背景和被排除的证据，并把原句改写到当前材料真正能支持的范围。

### 2:05–2:35｜新证据改变判断

**页面操作**：点击“加入不同观点材料”，再点击“重新核验当前结论”，展示新增冲突证据和更新后的结论状态。

**讲解词**：

> 新材料中，另一名模拟受访者认为步骤清楚并能独立完成。青迹不会隐藏相反观点，而会重新计算证据关系并显式标出冲突。判断随证据更新，而不是固定生成一个看似合理的答案。

### 2:35–3:00｜可信导出

**页面操作**：进入“成果与缺口”，快速展示结论列表、结论—证据对应表和“可信导出”。

**讲解词**：

> 最终产物不是一段无法追溯的 AI 文字，而是一份保留结论编号、证据编号、来源定位、冲突关系和未解决缺口的可审核成果。青迹让实践有迹可循，让结论有据可查。

## 完整流程加录：新建项目到结论核验

如果视频时长允许，可在主方案之后加录以下流程；这部分更能体现模型生成能力。

1. 在“项目概览”新建项目，名称填写“校园自习空间预约体验调研（模拟）”。
2. 进入“材料与证据”，上传演示 DOCX。
3. 核对自动识别的材料名称、来源角色、日期和采集场景；授权选择“已确认授权”，勾选“这是模拟演示材料”和确认框。
4. 点击“本地检查并生成证据卡”，展示隐私检查、脱敏文本、证据卡和待核验结论草稿。
5. 在“审核证据卡”中展开一张卡，展示模型建议与原文定位；勾选信任说明后，让模型审核下一批。每次最多 8 张，可清楚看到处理进度。
6. 进入“结论核验”，勾选一条模型提取的结论草稿，点击“核验已选结论”。
7. 展示四级状态、完整语义关系、范围规则、稳妥改写、补证任务和检索诊断。
8. 进入“成果与缺口”，展示结论—证据对应表并生成成果报告版 DOCX 或 PDF。

**这一段的讲解重点**：

> 从材料导入开始，模型只处理已授权、经过脱敏的内容。模型生成证据卡和结论草稿，但最终结论必须经过可引用证据检索和本地边界规则。人工可以随时修改或排除证据，系统会同步重核受影响的结论。

## 现场备用方案

- **模型或网络较慢**：直接使用内置模拟项目完成主方案；核心核验与导出可以离线运行。
- **时间不足**：省略证据卡展开，重点展示“过度推广 → 稳妥改写 → 加入不同观点 → 结果更新”。
- **页面刷新**：数据保存在本地 SQLite，重新进入对应页面即可继续。
- **只有 90 秒**：首页 15 秒，结论核验 35 秒，加入不同观点并重核 25 秒，可信导出 15 秒。

## 答辩表述边界

推荐表述：

- “青迹判断当前材料对结论的支持程度。”
- “模型负责生成和语义建议，本地规则负责最终四级状态。”
- “未授权和已排除证据不会进入核验，待复核状态会如实保留。”
- “内部评测使用虚构数据，只用于回归验证。”

避免表述：

- “系统已经判断事实真伪。”
- “系统可以替代团队完成采访、调研或人工审核。”
- “模拟评测成绩等于真实场景准确率。”
