## 下一轮评审输入

- 当前版本的完整测试记录。
- 首批真实项目的授权状态与材料类型。
- 双人标注分歧、漏召回、误召回和规则误报样例。
- 用户完成一次材料导入到成果导出的实际耗时与困惑点。

没有以上输入时，不启动向量数据库、全量多模态、真实多人账号或公网部署。
