# 青迹首批真实试用候选项目

## 当前结论

首批试用建议先从三个风险较低、主题差异明显的项目开始：红色遵义社会实践、新店镇家用电器普及率调查和指尖筑梦人工智能科普。医缕清新医院控烟与数智法治基层服务实践团保留为第二批候选，只有在授权、脱敏和撤回流程完成演练后再决定是否加入。

本清单只完成候选筛选，不代表任何材料已经获得处理授权。工作簿中的授权状态统一保留为未确认，负责人、保留期限和撤回联系人由项目负责人核实后填写。

## 第一批准入条件

每个项目必须同时满足以下条件，才能从候选改为可导入：

1. 项目负责人确认青迹试用用途和允许处理的材料范围。
2. 每份材料有可追溯授权依据、保留截止日期和撤回联系人内部代号。
3. 原文与脱敏副本分开保存，第二人完成脱敏抽查。
4. 首轮只使用可提取文字的材料，不纳入扫描件、图片、音频和视频。
5. 至少两名标注者能够独立完成标注，且不会提前看到对方结果。

## 启动顺序

QJ-P01 已进入授权准备，当前仍未获得材料处理授权。先对该项目完成授权登记和至少一份材料的脱敏抽查，再开始导入、双人标注、仲裁、撤回和删除演练。流程稳定后再加入 QJ-P02 和 QJ-P03。QJ-P04 与 QJ-P05 涉及更高敏感度，当前不导入材料，也不调用云端模型。
