# 青迹真实试用准备

本目录用于 `v1.4` 真实试用版的阶段 1。当前只建立流程、标注口径和记录模板，不在仓库中保存真实材料或个人信息。

## 文件

- `data-governance.md`：材料授权、脱敏、撤回、删除和备份流程。
- `annotation-guidelines.md`：双人独立标注、风险标签和分歧处理规则。
- `pilot-runbook.md`：3 至 5 个真实项目的小规模试用步骤、停止条件和交付物。
- `candidate-projects.md`：首批五个候选项目、风险分层和建议启动顺序。
- `projects/QJ-P01-intake.md`：红色遵义社会实践的授权、角色、脱敏和启动门禁清单。
- `../templates/青迹真实试用登记与标注模板.xlsx`：项目登记、材料治理、双人标注和使用记录工作簿。
- 应用内“真实试用记录”页可导出逐次记录 CSV 和项目基线摘要；摘要只汇总已完成会话，并说明耗时缺失和结果边界。

## 当前边界

- 只有获得明确处理授权并完成必要脱敏的材料才能进入试用。
- 试用数据与演示数据分开保存，工作簿只记录内部编号和状态，不记录真实姓名、联系方式或原文。
- 两名标注者先独立完成判断，再查看对方结果；分歧由第三人或项目负责人仲裁。
- 候选项目已经完成初步筛选；授权确认和材料导入仍需项目负责人逐项批准。
