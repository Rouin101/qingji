## 材料登记要求

每份获准材料使用 `QJ-P01-M001` 起的稳定编号。登记表只写编号、材料类型、来源角色、授权依据、允许用途、云端处理范围、脱敏状态、保留期限和撤回状态，不写真实姓名、联系方式或原文。

首轮只接收可提取文字的材料。扫描件、图片、音频和视频不进入本轮试用。公开网页或正式文件也需要记录来源位置、获取日期和允许用途，不能仅凭“公开可见”推定可以任意处理。
