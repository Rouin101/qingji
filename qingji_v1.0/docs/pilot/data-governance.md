# 青迹真实试用数据治理流程

## 适用范围

本流程适用于青迹 `v1.4` 真实试用阶段使用的访谈记录、观察记录、工作人员说明、正式文件和团队分析。它约束材料进入系统前后的处理，不替代学校、团队或合作单位已有的伦理和数据管理要求。

## 角色

| 角色 | 责任 |
| --- | --- |
| 项目负责人 | 确认用途、授权依据、保留期限、撤回方式和最终导出范围 |
| 材料管理员 | 登记材料、完成本地脱敏、维护原文与脱敏文件隔离 |
| 证据标注者 | 只在授权范围内标注证据关系和结论边界 |
| 复核人 | 检查授权、来源定位、脱敏和最终表述，不与初标者合并判断 |

同一人可以承担多个角色，但工作簿中仍需分别记录每一步的操作人和日期。

## 材料准入条件

材料必须同时满足以下条件才能进入青迹：

1. 用途明确，且与原授权范围一致。
2. 授权状态为已确认；口头授权应有可追溯记录。
3. 已确定撤回联系人、保留期限和删除方式。
4. 原文只保存在本地受控目录，工作簿不记录真实姓名、联系方式或原文片段。
5. 已完成必要脱敏，并由另一人抽查脱敏结果。
6. 如需调用云端模型，已单独确认允许发送再次脱敏后的必要片段。

授权未知、授权被拒绝、撤回处理中或无法完成必要脱敏的材料不得导入。

## 操作流程

### 1 项目登记

为每个试用项目生成不含身份信息的内部编号。记录主题、负责人内部代号、预计材料类型、敏感级别、保留期限和试用状态。

### 2 材料登记

每份材料生成内部编号，记录来源角色、材料类型、授权依据、允许用途和云端处理范围。真实姓名、电话号码、邮箱和精确住址不进入登记表。

### 3 本地脱敏

先保留只读原始副本，再生成脱敏副本。至少检查姓名、电话、证件号、邮箱、精确地址、单位内可识别岗位和少见事件组合。脱敏不能破坏证据含义、时间顺序和来源定位。

### 4 导入与试用

只导入授权已确认的脱敏副本。青迹中的授权状态、模拟标识、来源角色、场景和日期必须与登记表一致。云端模型调用只发送完成再次脱敏的必要内容。

### 5 导出与复核

成果导出前，复核材料编号、来源定位、证据审核状态、结论范围和未解决分歧。完整审计版和项目 ZIP 可能包含敏感信息，只能保存在受控位置。

## 撤回与删除

1. 收到撤回请求后，将材料状态改为撤回处理中，并暂停引用和新增模型调用。
2. 在青迹中排除相关证据，重新核验受影响结论，记录变化的结论编号。
3. 删除受控目录中的原文、脱敏副本和无需保留的导出文件。
4. 对含该材料的项目备份执行删除或重新生成，并记录处理结果。
5. 由复核人确认材料不可再检索、引用或恢复后，将状态改为已删除。

如果因学校制度或审计要求必须保留某类记录，应在授权前说明保留依据、范围和期限，不能在撤回后临时扩大保留范围。

## 备份与恢复

- 项目 ZIP 与数据库副本按敏感材料管理，不上传公开仓库或公共网盘。
- 备份文件使用不含真实姓名的项目编号命名，并记录生成时间、保管人和删除日期。
- 恢复演练使用隔离环境，恢复后检查授权状态、材料数量、审核历史和证据引用关系。
- 试用结束后，按登记的保留期限删除不再需要的原文、脱敏文件、导出和备份。

## 异常停止条件

出现授权不清、意外暴露个人信息、跨项目引用、无法删除材料、备份校验失败或云端发送范围超出授权时，应立即暂停该项目试用，保留最小必要的事件记录，并由项目负责人决定恢复或终止。
