# 青迹真实试用双人标注规范

## 标注目标

标注用于回答四个问题：某条结论应该检索哪些证据，这些证据与结论是什么关系，当前材料允许写到什么范围，以及应触发哪些越界风险。标注不判断现实世界中的最终真伪。

## 标注单位

每行是一条结论用例，使用内部项目编号和用例编号。结论原文可以进入工作簿，但不得包含真实姓名、联系方式或未脱敏细节。证据使用青迹中的稳定编号，例如 `E12;E18`，不复制原文。

## 独立标注流程

1. 标注者 A 和标注者 B 分别读取同一份已授权材料和结论，不查看对方结果。
2. 两人分别填写应检索证据编号、证据关系、四级结果、风险标签和可接受改写。
3. 两人都提交后，工作簿根据证据编号、关系、结果和风险标签显示初步一致状态；改写差异仍由人工检查。
4. 需仲裁用例由第三人或项目负责人查看两份理由和原材料后确定最终标注。
5. 仲裁不得覆盖两份原始标注；最终结果单独记录。

## 证据关系

| 值 | 使用条件 |
| --- | --- |
| 支持 | 证据直接支持结论核心事实，且主体、时间和范围相容 |
| 冲突 | 证据在同一核心事实上给出相反方向 |
| 背景 | 证据提供场景或解释，但不能单独支持核心事实 |
| 无关 | 与结论主题没有足够直接关系 |
| 混合 | 同一用例包含多条不同关系证据，应在证据编号中逐项说明 |

## 四级结果

- 已有支持：当前可引用证据足以支持原句，不需要缩小关键范围。
- 部分支持：材料支持更窄表述，但不支持原句中的数量、范围、程度、时间或因果强度。
- 暂无支持：没有足够直接的可引用证据。
- 存在冲突：当前可引用证据中存在同一核心事实的相反方向。

## 风险标签

可填写多个标签，用中文分号分隔：

- 数量范围：全部、多数、普遍、比例或材料数量不足。
- 否定方向：没有、从未、无法等绝对否定缺少充分证据。
- 强度程度：显著、严重、大幅等程度词超出材料。
- 因果关系：导致、造成、证明等因果词缺少研究设计支持。
- 时间范围：材料时间与结论时间不一致或无法覆盖变化。
- 地域范围：局部场景被扩大到更大区域。
- 主体不一致：材料中的人群、机构或对象与结论主体不同。
- 指标口径：指标定义、分母、比较基准或统计口径不一致。
- 来源定位：证据编号、页码、段落或时间位置无法复查。
- 授权资格：证据授权、审核或排除状态不满足引用条件。

## 可接受改写

改写应保留材料真正支持的核心内容，同时缩小超出证据的数量、范围、程度或因果表达。不能引入新事实，也不能用模糊措辞掩盖冲突。例如，把“学生普遍认为预约困难”改为“部分受访学生提到预约步骤较多”。

## 一致与分歧

证据编号、四级结果、主要证据关系和主要风险标签都一致，且可接受改写不存在实质边界差异时，才记为一致。以下情况必须仲裁：

- 四级结果不同。
- 一方认为存在冲突，另一方没有识别冲突。
- 一方引用了另一方认为无资格或无关的证据。
- 可接受改写在主体、数量、范围、时间或因果上有实质差异。

措辞差异但边界相同的改写可在仲裁说明中合并，不作为算法错误。

## 冻结规则

真实基线集 v0 冻结后，修改最终标注必须记录修改人、日期、原因和受影响用例。开发人员不得为了提高当前模型成绩直接修改标注；如发现规范问题，应先更新规范版本，再由标注者重新审阅相关用例。
