# 青迹 · 可信社会实践 Agent

青迹帮助实践团队把问题、行动、原始记录和报告结论连接起来：规划下一步实践，保留材料来源，用 AI 核对结论与证据之间的关系，并由作者决定修改、补证和交付。

## 当前开发版本

[青迹 3.0](qingji_v3.0/README.md) 是当前独立开发版本。界面以南大紫、白色和浅紫呈现，正文默认 16px，围绕项目概览、实践指导、行动与记录、材料管理和结论核验组织。

- 默认使用已配置 AI，无需反复勾选；材料可以明确排除。
- 没有核验历史也能进入核验页面，上传、粘贴或选择已保存材料作为报告。
- AI 反馈保留原句定位、材料引用、支持关系与核验历史；错误不会标记为成功。
- 导出报告及项目包，保留来源、行动和记录关系。

## 运行

```powershell
cd qingji_v3.0
python -m pip install -r requirements.txt
cd frontend
npm ci
npm run build
cd ..
python -B server.py --port 8770
```

浏览器打开 http://127.0.0.1:8770 。模型配置和完整说明见 [3.0 README](qingji_v3.0/README.md)。密钥、数据库与真实材料不随源码提供。

## 版本与边界

`qingji_v1.0`、`qingji_v2.0` 及仓库根目录早期代码保留用于历史参考，当前改进集中在 `qingji_v3.0`。

AI 生成的指导不等于已执行的行动；有引用不等于结论一定成立。青迹保留作者复核与决定，不代替田野调查、来源核实或专业判断。当前为本机应用，尚无跨设备实时协同。
