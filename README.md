# 青迹

**青迹——面向高校社会实践的可信证据链智能体**

青迹不替社会实践团队编造或“润色”事实。它把已授权材料整理为可追溯的证据卡，检查一句待写入报告的结论是否超出当前证据，并将未解决的问题转化为补证任务。

> 当前仓库内置的项目、人物、联系方式和社会实践材料均为虚构测试数据，仅用于功能演示，不对应任何真实受访者或真实调研结论。

## 项目状态（v0.9）

文字版可信证据链闭环已在本机离线跑通：

- 存储、脱敏、证据抽取、本地检索、结论规则、虚构演示数据、Markdown 导出与工作流模块均已就绪。
- 支持创建和切换多个项目，各项目的材料、证据、结论和补证任务相互隔离。
- 支持项目重命名、归档、恢复和安全删除；内置虚构测试项目不可删除。
- 支持按四级核验状态和关键词筛选历史结论、切换查看任意记录，并在项目概览查看结论状态分布。
- 每次核验会保存可解释检索诊断，包括候选排名、相关分、命中依据、阈值判断，以及因授权或审核状态被排除的材料。
- 证据批准、撤回或编辑后，会自动重新核验当前项目的全部结论，并同步关闭或重开系统生成的补证任务，避免旧判断继续引用已撤回证据。
- 每次人工批准、编辑或撤回证据都要求填写审核说明，并追加保存修改前后状态、变更字段、时间和触发重核的结论；审核历史不可通过公共接口修改或删除，并随可信导出一同保留。
- 固定检索回归集覆盖直接匹配、同义改写、无关主题零命中和正反观点同时召回。
- 用户项目可下载项目专属 CSV 模板，导入自定义查询、目标证据编号和零命中用例，在本地运行并保存分类评测结果；评测历史会标明用例集、证据集、检索版本、Top-K、阈值与可比性，并可导出 CSV/Markdown。
- 存储层禁止通过更新接口把材料、证据、结论、任务或运行记录重挂到其他项目；跨项目目标证据、完成材料和结论运行记录都会被拒绝。
- 内置演示项目仅接收虚构测试数据；用户新建项目可导入真实经授权材料，也可使用明确标注的虚构材料。
- **56 项自动化测试全部通过**，覆盖项目工作区、归档迁移、安全删除、证据审核日志、结论历史筛选与统计、证据撤回后的自动重核、检索诊断、评测历史与导出、跨项目隔离、脱敏规则、四级结论核验、SQLite 存储、工作流与四个页面的 AppTest 冒烟。
- 四个 Streamlit 页面在 AppTest 下均无异常。
- 已用 AppTest 驱动真实页面走通完整纵向闭环：导入材料 → 批准证据卡 → 核验结论（部分支持）→ 加入虚构相反观点 → 重新核验（存在冲突）→ 导出 Markdown。
- 已向赛事方确认：参赛作品可以不使用扣子工具，本项目继续采用单人自研路线。

> 结论核验当前是**确定性规则版**（强量词、因果表达、冲突立场 + 本地检索），尚未接入云端大模型；ASR、OCR、多智能体与知识图谱同样不在当前 v0.9 范围内。

## 当前可体验的闭环

1. 创建或切换社会实践项目。
2. 导入文字材料，如实填写真实/虚构属性、来源角色、采集场景与授权状态。
3. 在本地识别手机号、身份证号、邮箱以及用户指定的敏感词。
4. 查看脱敏后的证据卡，并人工批准或拒绝；证据状态或内容改变时，已有结论会自动按最新证据集重新核验。
5. 输入一句准备写进报告的结论，获得“已有支持、部分支持、暂无支持、存在冲突”四级结果。
6. 查看关联证据、稳妥改写与补证任务；加入新的经授权材料后重新核验。
7. 导出带证据编号、来源目录和未解决缺口的 Markdown。

## Windows PowerShell 运行

在项目目录 `C:\Users\葛浩东\Desktop\EL` 打开 PowerShell：

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

浏览器通常会自动打开 `http://localhost:8501`。如果 PowerShell 阻止当前终端激活虚拟环境，可以仅对当前进程放开后重试：

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
```

也可以不激活虚拟环境，直接运行：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

应用首次启动会在 `data\` 下建立本地 SQLite 数据库，并写入一套明确标注为虚构的演示项目。

## 运行测试

```powershell
python -m unittest discover -s tests -v
```

该命令运行全部单元测试与四页 AppTest 冒烟测试（当前 56 项全部通过）。`tests/test_app_pages.py` 会把数据目录重定向到临时文件夹，不会改动 `data\` 下的演示库。

如需自动走完整纵向闭环（导入 → 审核 → 核验 → 补证 → 重新核验 → 导出）：

```powershell
python scripts\e2e_apptest.py
```

该脚本用 Streamlit AppTest 驱动真实页面，并在隔离的临时数据库上断言每一步结果。

如需单独运行固定检索回归集：

```powershell
python scripts\eval_retrieval.py
```

当前回归集包含 6 个虚构固定查询：3 个直接匹配、1 个同义改写、1 个无关主题零命中和 1 个正反观点同时召回。正向目标必须进入前三名，零命中样例不得越过相关阈值；它用于防止检索规则修改后出现明显退化，不代表真实项目上的通用准确率。

用户项目还可以在“成果与缺口 → 检索评测”中下载 CSV 模板。每行填写用例名称、类别、查询、预期证据编号以及是否要求零命中。目标证据必须属于当前项目，并且已经确认授权、完成人工批准；跨项目编号会被拒绝。评测查询和结果仅保存在本地项目数据库中。

评测历史只在“用例集指纹、证据集指纹、检索版本、Top-K、相关阈值”全部一致时计算通过率变化，避免把语料或配置不同的成绩误当作性能升降。选中的运行可导出 Excel 安全的 UTF-8 CSV 或带边界声明的 Markdown；评测通过率不是事实正确率，也不是外部基准成绩。

也可以用项目脚本一次完成单元测试、语法检查和端到端验证：

```powershell
.\scripts\test.ps1
```

如要在完全独立的临时数据目录中手动试验，可先设置：

```powershell
$env:QINGJI_DATA_DIR = "$PWD\data-test"
python -m streamlit run app.py
```

## 数据与隐私边界

- 演示库只应使用虚构数据，不能把界面中的示例当作真实调研结果。
- 真实录音、笔记或图片必须先取得相应的记录与使用授权；授权状态未知或被拒绝的材料不得进入结论检索和成果导出。
- 手机号、身份证号、邮箱和自定义敏感词先在本地识别。只有人工确认后的脱敏文本才适合用于后续模型处理。
- 原始材料与脱敏文本分开保存；公开仓库不提交 `data\qingji.db`、`data\raw\`、`.env` 或其他含个人信息的文件。
- 证据卡由系统提取后仍需人工审核。团队分析不能单独证明事实，单名受访者的陈述也不能自动推广为群体结论。
- 青迹给出的是“当前材料能支持到什么程度”，不是事实认证、伦理审查或法律意见。导出前仍需项目成员复核原文和来源定位。


## 当前限制（v0.9）

- 结论核验为**确定性规则版**：只判断“当前材料能支持到什么程度”，识别强量词、因果表达与相反体验；尚未接入云端大模型。
- 证据检索基于本地关键词与中文字符 n-gram。与结论措辞差异较大的材料可能进入不了候选集，写结论时最好沿用材料中的关键用语。
- 当前 Retrieval regression@3 仅覆盖 6 个固定虚构样例，属于分类回归检查，不应表述为真实调研数据上的模型评测。
- 自定义评测的目标证据由用户人工指定，其质量取决于标注是否准确；评测通过率不能当作事实正确率或外部基准成绩。
- 只支持文字材料；录音转写（ASR）、图片 OCR、多智能体与知识图谱尚未接入。
- 已支持本地多项目，但仍是单用户应用，无账号系统与多人权限。
