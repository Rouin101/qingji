# 首页备份库验收

日期：2026-11-06。

## 实现

首页折叠入口统一搜索与分页查看本机主动备份，独立备份库不依赖原项目存在。预览共享项目包完整性和结构校验，仅返回数量和问题等概要；可比较当前项目元信息，明确恢复为独立副本。

损坏包拒绝预览恢复；工作库缺失可恢复，损坏工作库只提示下载留存，不自动覆盖修复。下载和精确删除保留原项目及其他备份。搜索通配符按普通字符处理，列表不返回材料正文。

## 验证

后端全量运行288项，287项通过；新增测试误把六字报告写成七字预期，已修正，包含该项的5项新测试全部复测通过。产品实现未因该测试期望修正而变更。覆盖预览只读比较、工作库文件丢失恢复、搜索分页、损坏包拒绝及损坏工作库仍保留备份。

59项前端、4项打包检查及构建通过。Edge隔离端口8786九组流程通过：首页搜索孤立备份、预览缺失提示、完整下载、恢复不覆盖、空搜索、损坏拒绝、失败重试、精确删除、390/768/1440布局。已检查手机截图。模型尝试0、外部HTTP尝试0。

复现：在3.0运行 `python -B scripts/seed_backup_library_qa.py`，用qa_server指向 `.browser-test-output/backup-library-20261106` 和新的审计文件，监听8786；随后在frontend运行 `node scripts/backup-library-qa.mjs`。种子只移除自身创建的虚构项目，不删除其他数据。

## 边界

仍需主动保存备份，不是定时或异地备份。原上传文件、未保存浏览器草稿和服务配置不在包内。损坏工作库的修复不属于此入口；同设备损坏仍可能影响工作库和备份库，应另存下载包。
