# 阶段分析历史与交接验收

日期：2026-11-06。

## 实现

成功分析保存到独立历史表，来源快照与结果一同保存；读取不会调用模型或改正文。最多20次，不自动淘汰。校验引用、来源指纹、数量、体积和版本，保存事务再次检查项目版本。历史删除仅影响选中记录。

页面重开自动展示最近分析，支持旧轮次切换、当时来源快照、下载和删除。输入变化或导入状态导致历史仅可回看，不可直接带入正文或起草行动；无关项目修改可继续使用当前来源未变的分析。

3版项目包保留分析历史，导入标为外部未复核；无分析历史继续导出2版包，1/2版兼容。备份判重由仅看正文版本改为比较完整项目包内容，避免遗漏同版本新增分析。旧客户端不能导入3版包。

## 验证记录

新增7项后端测试：接口成功即持久化、无关版本更新与来源过期、包和备份往返、容量先于模型调用、删除隔离、篡改/降级拒绝、并发保存拒绝。

前端59项、打包4项及构建通过；过期候选保护增加定向断言并通过。Edge使用已校验虚构历史种子，验证重开读取、切换历史、快照下载、来源变化后仅回看、包导入保留且未复核、指定副本删除与三种屏宽。未调用真实模型。

首次全量出现一项5秒本地接口超时及其清理连带错误，失败测试组单独复测通过；浏览器脚本首次错误假定刷新后仍停在项目内，改为明确重新打开项目后通过。

历史快照只保存本轮已脱敏文本，不含原上传文件二进制或模型配置。旧历史仍需人工解释，不认证事实或自动解决问题。

最终重跑：283 项后端全部通过。最终样式构建后，浏览器八组流程再次通过。

复现浏览器验证：先运行 `python -B scripts/seed_analysis_history_qa.py`，再用 `scripts/qa_server.py` 指向 `.browser-test-output/history-20261106`、独立且未存在的审计文件并监听8785，最后在 frontend 目录运行 `node scripts/analysis-history-qa.mjs`。全部为虚构种子，不调用模型。
