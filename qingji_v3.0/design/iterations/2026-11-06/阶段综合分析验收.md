# 阶段综合分析验收

日期：2026-11-06。

## 实现

按单个实践问题调用配置中的模型，结构化返回已有记录理解、不同反馈、待了解事项和限制。每项均强制关联记录及原文引文；不同反馈至少两份材料。引文存在校验不保证语义蕴含或事实真实性。未增加持久数据结构，结果只在当前页面暂存，可下载；不写报告、任务或记录。

仅发送当前问题的纳入关联材料及团队备注，复用隐私遮盖与材料预算；模型不能读取未提供材料。上下文 60,000 字、响应 24,000 字，超限拒绝。调用前后项目版本检查，页面切换问题、版本或卸载会取消接收旧结果。取消浏览器等待不保证提供方立即终止计算。
