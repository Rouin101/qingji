# 阶段记录来源状态筛选

## 实现
现有问题、行动和搜索之外，增加来源状态筛选。待核对汇集来源修改与来源移除；排除作为独立状态，允许与来源修改同时存在。沿用服务端来源指纹判断，不将“未显示提醒”等同于报告通过。来源状态未返回时显示读取提示，不把读取中的空列表当作没有待核对项。

## 验证范围
虚构隔离项目验证来源变更、缺失、排除、两种状态同时存在，问题与关键词联合筛选、空结果恢复、任务入口重置旧筛选、记录草稿保留和只读项目版本。检查 390/768/1440 宽度，并回归交付检查逐条定位流程。本轮仅改前端，无后端变更和真实模型调用。

## 验收结果

51 项前端测试、4 项打包检查及构建通过。来源状态筛选与交付单条定位两条 Edge 流程均通过，无页面异常；正式本地首页 HTTP 200、插图加载正常。隔离服务模型与外发请求均为 0。
