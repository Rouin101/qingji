# 青迹 3.0 · UI 与交互升级验收

日期：2026-10-15。开发范围仅 qingji_v3.0。可运行页面：http://127.0.0.1:8770/ 。本报告截图全部使用隔离库中的虚构材料。

## 设计判断：实测问题与建议分开

**浏览器实测发现**：旧项目页将指导、记录、报告、团队、行动与历史纵向串接；已有行动入口位于很靠下的位置。新建页先铺开可后补的四项条件，使问题输入下移。无报告的材料空状态仍提示先核对报告内部依据。首页报告入口收起时只剩右侧一行文字，与新实践起点不平衡。

**设计建议及本轮实现**：项目页分为概览、实践指导、行动与记录，分别保留完整能力；沿用全局实践材料和结论核验导航。首页用两张内容入口卡片承接不同起点，减少重复统计。以南大紫为重点、浅紫为分区、白色为工作表面；地图呼应走访方向，记录纸呼应原始资料。没有照搬参考站的品牌、红色体系、内容或整页布局。

1.0 为只读参考：实际打开了旧版已存首页截图 str/tmp/ui-audit-20260922/01-home.png，并核对 qingji/ui.py 的配色与层次。1.0 服务当时未运行，本轮没有启动或改动旧版。3.0 的现状与改版均实际通过 Edge 浏览器检查，不把旧截图当成本轮3.0现状。
